        CONCEPTO CLAVE — ARQUITECTURA DE COLORES
        ──────────────────────────────────────────────────────────
        TODOS los colores del sistema deben definirse como CSS custom
        properties (variables) inyectadas dinámicamente desde la BD.
        NADA de colores hardcodeados en FiyiPOS.css para valores que
        el usuario podría querer cambiar (fondo, primario, acento, etc.).
        El Scheme Manager es el módulo que permite editar esas variables
        y persistirlas. La UI nueva (fondo mint, etc.) no es un valor fijo:
        es simplemente el preset por defecto que el Scheme Manager carga.
